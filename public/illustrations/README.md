# Ilustrasi SIGAP DIARE

Taruh file gambar di folder ini dengan **nama persis** seperti tabel di bawah. Website otomatis memakainya
(urutan dicari: `.webp`, `.png`, `.jpg`, `.svg`). Selama file belum ada, tampil ilustrasi SVG sederhana.
Tidak perlu mengubah kode; cukup muat ulang halaman (pada produksi: build/deploy ulang).

| Nama file | Dipakai di | Isi yang disarankan |
|---|---|---|
| `keluarga.png` | Hero halaman awal & beranda | Orang tua memeluk/menggendong balita, ceria (boleh ibu atau ayah) |
| `edukasi.png` | Halaman Edukasi | Anak/balita dengan buku, atau orang tua membaca bersama anak |
| `fitur.png` | Halaman Fitur | Orang tua memegang ponsel sambil tersenyum |
| `tanda-bahaya.png` | Halaman Tanda Bahaya | Orang tua menggendong anak yang lemas dengan raut peduli (tidak menakutkan) |
| `catatan.png` | Catatan Diare | Anak + papan catatan/checklist |
| `kuis.png` | Kuis Pengetahuan | Papan kuis/clipboard dengan centang |
| `tanya-jawab.png` | Tanya Jawab | Gelembung percakapan / orang tua bertanya ke tenaga kesehatan |

Spesifikasi:

- Latar **transparan** (PNG/WebP), rasio sekitar **4:3**, lebar minimal **1200 px**, ukuran file sebaiknya < 300 KB (WebP).
- Gaya: kartun lembut, garis membulat, warna pastel (biru, hijau, kuning, merah muda) seperti mockup.
- Tokoh beragam (ibu berkerudung/tidak, ayah, nenek), latar rumah & puskesmas Indonesia.
- **Jangan** memuat teks takaran/dosis di dalam gambar (aturan keselamatan proyek).
- Pastikan lisensinya boleh dipakai (buatan sendiri/ilustrator/AI dengan hak pakai).
